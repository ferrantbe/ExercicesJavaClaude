# Une ligne par entree :      Entree | forme cherchee ; autre forme
#   - « Entree > sous-entree » cree une sous-entree, rangee sous l'entree ;
#   - une forme entre accents graves (`static`) n'est cherchee que dans du
#     code (Consolas) ; sans accents graves, dans le texte courant, sans
#     tenir compte des majuscules ;
#   - sans « | », c'est l'entree elle-meme qui est cherchee.
# Une entree est marquee dans les titres ou elle apparait, la ou elle est
# definie (en italique), et a sa premiere occurrence dans chaque section
# (POO §4, TMP §7...) : elle renvoie a quelques pages, pas a toutes.
# Une ligne qui commence par # est un commentaire.
